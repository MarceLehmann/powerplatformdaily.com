## TL;DR

PACX now supports PowerShell tab completion, helping users discover commands and recall arguments or values while scripting in an existing terminal workflow. The feature complements PACX interactive mode rather than replacing it, and installation instructions are documented in the PACX wiki.

## Why it matters

- Makers: Enable the documented PACX PowerShell completion to reduce typing and make command exploration more natural in an existing terminal workflow.
- Makers: Use completion when scripting commands for later use, while keeping --interactive mode for discovering commands and options during one-off or fire-and-forget work. The two experiences complement each other rather than replacing one another.
