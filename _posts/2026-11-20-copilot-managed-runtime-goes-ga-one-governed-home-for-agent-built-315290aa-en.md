## TL;DR

A source of 2026-11-18 reports Microsoft announcing Copilot Managed Runtime in general availability at Ignite 2026: governed hosting and execution for apps built in Code, Cowork, Copilot Studio or third-party tools. Fabric integration adds an optional backend for persistence, databases and data APIs. Agents and Workflows, local development of Copilot Studio agents and flows via CLI with GitHub versioning, has no stated availability date.

## Why it matters

- Makers: Build Copilot Studio agents and flows locally and publish them via CLI with GitHub version control once Agents and Workflows arrives; the source gives no availability date yet.
- Admins/IT: Treat Managed Runtime as the governed home for apps born in Code, Cowork or Copilot Studio, and define ownership, permissions and access controls from day one.
- BI/Data teams: Fabric appears here as an optional backend for persistence, databases, storage and data APIs; the source stresses it does not replace the runtime.
