## TL;DR

Der Microsoft Release Communications MCP Server gibt Copilot Studio und GitHub Copilot in VS Code Zugriff auf aktuelle Daten der Microsoft AI at Work Roadmap. Den HTTP-Server hinzufügen, die vier Tools auswählen, die Nutzung für Roadmap-Fragen anweisen und den Agent für Microsoft 365 Copilot und Teams veröffentlichen.

{% include curated-attribution.html %}

## Warum das wichtig ist

- Makers: Den MRC MCP Server in Copilot Studio unter Tools hinzufügen und seine Nutzung für Roadmap-Fragen anweisen, damit Antworten aktuelle Release-Daten verwenden.
- Admins/IT: Die verfügbaren MCP-Tools und die Verbindung prüfen, wobei der Server keine Authentifizierung und keine separate Lizenz benötigt.
- Leadership/Business: Den veröffentlichten Release-Radar in Microsoft 365 Copilot oder Teams bereitstellen, damit Mitarbeitende bevorstehende Änderungen und nötige Vorbereitungen verfolgen können.
