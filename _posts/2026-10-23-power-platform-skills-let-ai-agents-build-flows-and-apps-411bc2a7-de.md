## TL;DR

Power Platform Skills ermöglichen KI-Coding-Agenten wie Claude Code und GitHub Copilot, Power Platform Flows und Apps direkt in Umgebungen zu erstellen. Dadurch verändert sich, wer dort bauen kann, und die Bedeutung einer Sandbox wird für die sichere Nutzung zentral.

{% include curated-attribution.html %}

## Warum das wichtig ist

- Makers: Prüft, wie Power Platform Skills Claude Code oder GitHub Copilot Flows und Apps direkt in euren Umgebungen erstellen lassen, weil sich dadurch der Kreis der Erstellenden verändert.
- Admins/IT: Legt fest, was eine Sandbox bedeutet, und prüft ihre Grenzen vor der Nutzung, weil direkter Agentenzugriff die Anforderungen an sicheres Erstellen erhöht.
