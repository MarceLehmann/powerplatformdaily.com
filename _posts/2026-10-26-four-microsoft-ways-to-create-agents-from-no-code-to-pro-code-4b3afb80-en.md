## TL;DR

Microsoft presents four agent entry points: SharePoint agents for existing content, Agent Builder for natural-language no-code agents, Copilot Studio for actions and integrations, and Microsoft Foundry for deeper model, code and architecture control.

{% include curated-attribution.html %}

## Why it matters

- Makers: Use SharePoint agents or Agent Builder for knowledge-focused scenarios, then consider Copilot Studio when the agent must perform actions.
- Admins/IT: Match each option to the required integrations, autonomy, governance and development control instead of treating them as interchangeable.
- Leadership/Business: Decide who should create each agent and provide the appropriate entry point, from no-code experiences to professional development.
