## TL;DR

Laut Quelle vom 24.11.2026 heißt der GitHub Copilot Harness jetzt Microsoft Copilot Harness. Eingeführt mit dem überarbeiteten Copilot Studio im Sommer, treibt er Copilot Studio, Copilot Code, Cowork, Foundry, VS Code und GitHub Copilot an. Microsoft Copilot selbst läuft weiter auf dem Copilot Chat Harness, was laut Autorin für Verwirrung bei Copilot-Lizenzinhabern sorgt.

## Warum das wichtig ist

- Maker: Beim Harness in Copilot Studio trägt die Standard- oder Copilot Chat Variante die inkludierte Nutzung für Copilot Lizenzen, nicht der neu benannte Microsoft Copilot Harness.
- Admins/IT: Eine einfache Erklärung bereithalten für alle, die erwarten, dass der Microsoft Copilot Harness hinter Microsoft Copilot selbst steckt, und die Ignite Ankündigungen der nächsten Wochen im Blick behalten.
