## TL;DR

Das Computer-Use-Tool in Microsoft Copilot Studio ermöglicht Agenten Web- und Windows-Desktop-Aufgaben wie Formulare, Dateneingabe, Rechnungsverarbeitung und Datenextraktion ohne direkten API-Zugriff. Das Tool wird über die Registerkarte Tools eingerichtet: Aufgabe in natürlicher Sprache beschreiben, detaillierte Anweisungen ergänzen, speichern und die ausgeführten Schritte mit Screenshots testen.

{% include curated-attribution.html %}

## Warum das wichtig ist

- Makers: Computer Use über die Registerkarte Tools hinzufügen, die Aufgabe klar beschreiben und detaillierte Anweisungen geben, damit der Agent interfacebasierte Arbeit zuverlässig ausführt.
- Makers: Aufgaben wie das Absenden eines Kontaktformulars testen und Screenshots, ausgeführte Schritte, Fehler sowie Echtzeit-Feedback vor dem Einsatz prüfen.
- Admins/IT: Computer Use als Vorschaufunktion behandeln und beobachten, wie Agenten auf Pop-ups, verschobene Schaltflächen und andere Interface-Änderungen reagieren.
