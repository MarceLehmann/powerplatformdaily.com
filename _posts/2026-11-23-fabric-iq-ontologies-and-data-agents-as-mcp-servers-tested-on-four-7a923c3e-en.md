## TL;DR

According to the source of 2026-10-18, Fabric IQ adds a semantic intelligence layer whose ontologies name business relationships, so agents skip prompt engineering; in the speaker&\#39;s test, answers improved measurably, but Fabric IQ is preview, not production-ready in her view. Fabric data agents publish as MCP servers with one tool for Copilot Studio; a wholesalers&\#39; ontology over four million products enabled a warm downlight recommendation.

## Why it matters

- Makers: Build a first Fabric data agent on a real dataset in a dev workspace and test its MCP integration in Copilot Studio, where the data simply appeared as a tool.
- BI/Data teams: Check whether your data is ontology-ready; named relationships gave the case study&\#39;s agents a shared vocabulary across the silos that survive every consolidation project.
- Leadership/Business: Treat Fabric IQ as preview, not production-ready per the speaker, but watch the IQ family, since Microsoft is investing heavily and a large Ignite theme was expected.
