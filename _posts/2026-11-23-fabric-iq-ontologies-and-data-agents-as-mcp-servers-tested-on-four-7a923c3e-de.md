## TL;DR

Laut Quelle vom 18.10.2026 ergänzt Fabric IQ eine semantische Intelligenzschicht, deren Ontologien Entitätsbeziehungen benennen, sodass Agents auf Prompt Engineering verzichten können; im Test des Vortrags fielen die Antworten messbar besser aus, doch Fabric IQ bleibt Vorschau und ihrer Ansicht nach nicht produktionsreif. Fabric Data Agents werden bei Veröffentlichung zu MCP-Servern mit einem Tool für Copilot Studio; eine Ontologie über vier Millionen Produkte ermöglichte eine Warmlicht-Downlight-Empfehlung.

## Warum das wichtig ist

- Makers: Einen ersten Fabric Data Agent auf einem echten Dataset in einem Dev-Workspace bauen und die MCP-Integration direkt in Copilot Studio testen.
- BI/Data teams: Prüfen, ob die eigenen Daten ontologiefähig sind; benannte Beziehungen gaben den Agents im Fallbeispiel einen gemeinsamen Wortschatz über Silos hinweg.
- Leadership/Business: Fabric IQ als Vorschau behandeln und beobachten, da Microsoft laut der Referentin stark investiert und ein großes Ignite-Thema erwartet wurde.
