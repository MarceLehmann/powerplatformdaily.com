## TL;DR

Copilot Studio&\#39;s February 2026 update improves ticket-based Microsoft 365 Graph connector responses for ServiceNow and Azure DevOps data. It adds Claude Sonnet 4.5 beta for Computer Use agents, Claude Opus 4.6 and Sonnet 4.5 in prompt builder, per-prompt moderation sensitivity, and in-agent prompt editing.

## Why it matters

- Makers: Test Claude model choices and edit prompts, inputs, knowledge sources, and tests in the agent interface to refine agent behaviour.
- Admins/IT: Set moderation sensitivity per prompt where sensitive-content filtering needs to match the scenario.
- Makers: Use ticket-based Graph connector responses to present clearer summaries and actions from ServiceNow tickets or Azure DevOps work items.
