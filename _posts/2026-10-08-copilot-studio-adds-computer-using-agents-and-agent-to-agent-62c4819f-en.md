## TL;DR

Copilot Studio’s May 2026 update makes computer-using agents and agent-to-agent communication generally available. Computer-using agents automate user interfaces without an API, while the visual designer supports multi-agent orchestration without an SDK. A redesigned workflow canvas combines deterministic, branching and AI steps, with the source reporting approximately 20% better evaluations and 50% lower token usage.

## Why it matters

- Makers: Test computer-using agents against portal tasks that previously lacked APIs, because the feature supports UI automation with enterprise credentials and adaptive interface recovery.
- Admins/IT: Review Copilot Studio environments for the May release and assess agent-to-agent communication, because Studio-built and SDK-built agents are described as wire-compatible.
- Leadership/Business: Recalculate running-agent costs under Copilot Credits, because consumption pricing became effective on June 1 and pay-as-you-go is now available.
