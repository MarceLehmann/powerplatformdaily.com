## TL;DR

Xrm Tools 1.5.9 adds Dataverse Explorer, a Visual Studio tool window for inspecting Dataverse assemblies, plugins, plugin steps, images, Custom APIs, input parameters and output properties. Selecting a node shows its properties and can open matching solution code in the preview tab, while options allow workflow customization.

- Makers: Use Dataverse Explorer to inspect deployed assemblies, plugins, steps, images and Custom APIs from Visual Studio, giving you a direct view of what exists in the environment.
