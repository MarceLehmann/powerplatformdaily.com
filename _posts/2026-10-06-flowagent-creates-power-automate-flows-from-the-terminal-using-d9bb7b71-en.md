## TL;DR

FlowAgent is an open source Model Context Protocol server that lets terminal assistants create, edit, diagnose and maintain Power Automate flows with natural language. It includes 52 tools, supports Power Automate Desktop flows, and runs as a 1.5 MB Node.js file without Docker, remote servers or large npm installations.
