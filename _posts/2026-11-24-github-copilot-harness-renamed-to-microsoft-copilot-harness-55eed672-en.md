## TL;DR

According to the source of 2026-11-24, the GitHub Copilot harness has been renamed the Microsoft Copilot harness. Introduced with the upgraded Copilot Studio in the summer, it now powers Copilot Studio, Copilot Code, Cowork, Foundry, VS Code and GitHub Copilot. Microsoft Copilot itself still runs on the Copilot Chat harness, a naming gap the author expects to confuse Copilot license holders.

## Why it matters

- Makers: When choosing a harness in Copilot Studio, remember the Standard or Copilot Chat harness is what carries included usage for Copilot licenses, not the newly named Microsoft Copilot harness.
- Admins/IT: Prepare a plain explanation for users who expect the Microsoft Copilot harness to sit behind Microsoft Copilot itself, and watch Ignite in the coming weeks for follow-up announcements.
