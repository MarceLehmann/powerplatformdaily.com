## TL;DR

Microsoft Copilot Studio&\#39;s Computer Use tool lets agents perform web and Windows desktop tasks such as form completion, data entry, invoice processing and data extraction without direct API access. Configure it from the Tools tab, describe the task in natural language, add detailed instructions, save it and test the resulting steps with screenshots.

## Why it matters

- Makers: Add Computer Use from the Tools tab, describe the task clearly, and provide detailed instructions so the agent can execute interface-based work accurately.
- Makers: Test tasks such as contact-form submission and inspect screenshots, step execution, errors and real-time feedback before deployment.
- Admins/IT: Treat Computer Use as a preview feature and monitor how agents respond to pop-ups, moved buttons and other interface changes before production use.
