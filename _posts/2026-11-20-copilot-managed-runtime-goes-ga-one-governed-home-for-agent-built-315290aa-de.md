## TL;DR

Laut Quelle vom 18.11.2026 kündigte Microsoft Copilot Managed Runtime in allgemeiner Verfügbarkeit an: ein Umfeld für Hosting, Ausführung und Governance von Apps aus Code, Cowork, Copilot Studio oder unterstützten Drittanbieter-Tools. Die neue Fabric-Integration bietet laut Quelle ein optionales Backend für Persistenz, Datenbanken, Speicher und Daten-APIs. Agents and Workflows für lokale Entwicklung von Copilot Studio Agents und Flows per CLI mit GitHub-Versionierung wird ohne Verfügbarkeitsdatum angekündigt.

## Warum das wichtig ist

- Makers: Copilot Studio Agents und Flows lokal entwickeln und per CLI mit GitHub-Versionierung veröffentlichen, sobald Agents and Workflows kommt; die Quelle nennt noch kein Verfügbarkeitsdatum.
- Admins/IT: Managed Runtime als verwaltetes Zuhause für Apps aus Code, Cowork oder Copilot Studio einstufen und früh Eigentum, Berechtigungen und Zugriffskontrollen festlegen.
- BI/Data teams: Fabric dient hier als optionales Backend für Persistenz, Datenbanken, Speicher und Daten-APIs und ersetzt das Runtime laut Quelle nicht.
