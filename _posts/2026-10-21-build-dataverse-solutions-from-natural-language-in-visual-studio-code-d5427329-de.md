## TL;DR

Visual Studio Code, Claude Code und Microsoft Dataverse-Funktionen erstellen per natürlicher Sprache eine Dataverse-Umgebung, ein Authentifizierungsprofil, eine Lösung, einen Publisher, ein Ausgaben-Datenmodell und Beispieldaten. Die Anleitung zeigt ausserdem die Nutzung des Dataverse-MCP-Servers und der PAC-Werkzeuge.

{% include curated-attribution.html %}

## Warum das wichtig ist

- Makers: Visual Studio Code mit Power Platform Tools und Dataverse-Funktionen einrichten, um Dataverse-Objekte per Prompt statt über Portalseiten zu erstellen.
- Admins/IT: Die erforderlichen Mandantenrechte bereitstellen und Bestätigungsabfragen prüfen, weil Umgebungserstellung und Anmeldung weiterhin Berechtigungen benötigen.
- BI/Data teams: Feldtypen und Beziehungen präzise formulieren, da im Beispiel Dezimalfelder nachträglich in Währungsfelder geändert wurden.
- Leadership/Business: Agentische Werkzeuge als Produktivitätshilfe einordnen, nicht als Ersatz für Dataverse-Wissen und Lösungsarchitektur.
