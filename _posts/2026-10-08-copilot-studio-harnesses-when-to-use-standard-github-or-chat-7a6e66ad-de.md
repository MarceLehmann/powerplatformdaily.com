## TL;DR

Copilot Studio Agents können den Standard-, GitHub Copilot- oder Copilot Chat Harness nutzen. Standard passt zu festen, regelbasierten Prozessen, GitHub Copilot zu komplexer, denkintensiver Arbeit und Copilot Chat zu Erlebnissen in Microsoft 365 Copilot Chat mit Unternehmenswissen. GitHub Copilot unterstützt ausserdem hochgeladene Markdown-Skills und verwendet Copilot Credits für Agents und Workflows.

## Warum das wichtig ist

- Makers: Ordnet den Harness der Arbeitsform zu. Nutzt Standard für definierte Workflows, GitHub Copilot für offene Denkaufgaben und Copilot Chat für Erlebnisse in Microsoft 365.
- Admins/IT: Prüft den Verbrauch von Copilot Credits bei der Lösungsplanung, weil Agents, Workflows und Workflow-Trigger im GitHub Copilot Harness Credits verwenden.
- Leadership/Business: Entscheidet, wo Nutzende den Agent erleben sollen und ob der Prozess vorhersehbare Ergebnisse oder eine flexiblere, zielorientierte Ausführung braucht.
