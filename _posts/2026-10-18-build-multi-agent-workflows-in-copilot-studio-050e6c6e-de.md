## TL;DR

Copilot Studio teilt in diesem Beispiel eine einzelne Aufgabe auf drei Agenten auf. Jeder Agent erhält einen engeren Schwerpunkt, und die Agenten können parallel ausgeführt werden, um laut Quelle eine höhere Qualität erreichen zu können.

{% include curated-attribution.html %}

## Warum das wichtig ist

- Makers: Nutzt das gezeigte Copilot-Studio-Muster, um eine Aufgabe auf drei Agenten aufzuteilen, jedem Agenten einen engeren Schwerpunkt zu geben und Agenten parallel auszuführen, sofern der Workflow dies erlaubt. Der Ansatz soll höhere Qualität durch klarere Zuständigkeiten unterstützen.
- Leadership/Business: Betrachtet Multi-Agent-Workflows als Designoption für Aufgaben, bei denen Qualität wichtig ist. Die Quelle verknüpft engere Agenten-Schwerpunkte mit höherer Qualität, liefert aber keine gemessenen Ergebnisse oder einen Vergleich mit Einzelagenten.
