## TL;DR

FetchXML Builder AI Chat will use five readable Markdown instruction files covering system rules, behavior, style, preferences and user flavors. The next release also adds configurable strictness, personal response guidance, language preferences and manual model selection, while retaining common settings in the existing XML file.

## Why it matters

- Makers: Review the five instruction areas and define a useful personal flavor, because the AI can apply guidance about naming, tone, output format and user-specific conventions.
- Admins/IT: Check the provider, model, API key and endpoint settings, then note that the next release allows the model to be selected manually as models change.
