## TL;DR

Announced at Ignite 2026 and reported on 2026-11-18, Windows 365 for Agents provides managed Cloud PCs that agents can operate through windows and desktop apps. The computer use tool is available in the Copilot Studio Standard harness, Copilot Credits now bill eligible scenarios by consumption, and a Copilot harness preview is planned for December 2026, with Foundry MCP integration expected in early 2027 preview.

## Why it matters

- Makers: use the computer use tool in the Standard harness to drive legacy desktop apps that lack APIs, and plan for the Copilot harness preview announced for December 2026.
- Admins/IT: test agent desktop workflows on a controlled Cloud PC first, watching session expiry, screen-state changes and credit consumption before wider rollout.
- Leadership/Business: treat persistent Cloud PCs via Frontier and the Foundry MCP integration as announced previews, not generally available features.
