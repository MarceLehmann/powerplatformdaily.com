## TL;DR

Use a Microsoft 365 Instant Sandbox, activate the Power Apps Developer Plan, verify Dataverse and start the Copilot Studio trial in the dedicated developer environment. The guide recommends building a SharePoint knowledge agent first, then adding a Power Automate action to learn retrieval and execution together.

{% include curated-attribution.html %}

## Why it matters

- Makers: Activate the Power Apps Developer Plan and build in its dedicated Dataverse-backed environment, rather than the shared default environment.
- Admins/IT: Check the developer environment name, region and Dataverse provisioning before building, because the region cannot be changed later.
- Makers: Start with a SharePoint knowledge agent, then add a Power Automate action to practise knowledge retrieval and execution.
- Leadership/Business: Treat the Copilot Studio trial as an exploration period, because agents become read-only and stop responding when active Copilot Credits are unavailable after expiry.
