## TL;DR

Wie die Quelle vom 18.11.2026 zur Microsoft Ignite 2026 berichtet, stellen Windows 365 for Agents verwaltete Cloud PCs bereit, mit denen Agenten über Desktopoberflächen arbeiten. Das Computer-Use-Tool ist im Copilot Studio Standard harness verfügbar, Copilot Credits lassen sich in geeigneten Szenarien bereits nutzungsbasiert abrechnen, und eine Copilot harness Vorschau ist für Dezember 2026 angekündigt; die Foundry MCP Integration folgt erst früh 2027 als Vorschau.

## Warum das wichtig ist

- Makers: Das Computer-Use-Tool im Standard harness für Legacy-Desktopanwendungen ohne API testen und die für Dezember 2026 angekündigte Copilot harness Vorschau einplanen.
- Admins/IT: Agentenabläufe zuerst auf einem kontrollierten Cloud PC erproben und dabei Sitzungsabbrüche, Bildschirmzustände und Creditverbrauch beobachten, bevor ein breiter Rollout folgt.
- Leadership/Business: Persistenten Cloud PCs über Frontier und die Foundry MCP Integration nur als angekündigte Vorschauen einstufen, nicht als verfügbare Funktionen.
