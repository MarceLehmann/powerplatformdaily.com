## TL;DR

Copilot Studio agents can use Standard, GitHub Copilot or Copilot Chat Harnesses. Standard suits fixed, rule-based processes, GitHub Copilot suits complex or reasoning-heavy work, and Copilot Chat suits experiences built around Microsoft 365 Copilot Chat and enterprise knowledge. GitHub Copilot Harness also supports uploaded Markdown skills and uses Copilot Credits for agents and workflows.

## Why it matters

- Makers: Match the harness to the work shape. Use Standard for defined workflows, GitHub Copilot for open-ended reasoning, and Copilot Chat when the experience belongs in Microsoft 365.
- Admins/IT: Check Copilot Credit usage during solution design because agents and workflows in the GitHub Copilot Harness consume credits, including workflow triggers.
- Leadership/Business: Decide where users should experience the agent and whether the process needs predictable outcomes or more flexible goal-oriented execution.
