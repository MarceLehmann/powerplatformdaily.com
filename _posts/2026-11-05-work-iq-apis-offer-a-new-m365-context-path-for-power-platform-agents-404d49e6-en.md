## TL;DR

Work IQ APIs provide Chat, Context, Tools and Workspaces domains for agent architectures. The source says Copilot Studio agents, Power Automate flows and custom connectors can use the MCP surface instead of assembling multiple Microsoft Graph calls, with 10 generic tools and 80% fewer tokens in Microsoft internal testing.

## Why it matters

- Makers: Compare Work IQ with Graph-based custom connectors when agents need email, calendar or Teams context, because the source describes fewer tools and pre-processed context.
- Admins/IT: Check the tenant consent requirement before enabling the Work IQ MCP server, because first access requires administrative approval.
- Leadership/Business: Assess consumption-based Copilot Credits and the reported testing results separately, because the 80% token reduction was observed in Microsoft internal testing.
